# 法规对照矩阵 · Regulatory Traceability Matrix（LeebertyPV）

本文档把系统的每一项控制措施映射到具体法规条款，供验证文件（URS / IQ / OQ）与
检查时直接引用。**这是可审查的追溯证据，不是营销材料。**

**条款号来源与核实状态：**
- 中国法规条款号（81 号令、NMPA《药物警戒质量管理规范》2021、疫苗管理法、
  2010 年监测方案、2012 年 PSUR 撰写规范）一律取自
  [`docs/PV调研报告_中国MAH.md`](PV调研报告_中国MAH.md) 中标注 **【已核实】** 的
  条款号，以及 `seed/workflows/*.json` 的 `regulationRefs` 原文；**未核实的条款号
  不写入本文档**。
- 国际标准（21 CFR Part 11、ICH E2 系列、EU GVP Module I/VI/IX/XVI、ICH Q10）
  为国际通行条款号。

> ⚠️ 使用前请再次核对最新法规版本；条款号以政府发布原文为准。

## 十四、明确不在范围内的事项

诚实界定范围，避免过度声明：

1. **不替代程序文件与质量体系文件**。系统强制填写理由、保留审计追踪，但 SOP、
   PSMF 等文件内容仍需站点自行编写。
2. **不替代人员培训与资质认定**。系统管理培训记录与资质门槛，培训内容与效果
   评估由站点负责。
3. **不替代验证活动**。系统提供证据与就绪度输入，IQ/OQ 签署仍须站点执行
   （见 `docs/validation-guide.md`）。
4. **不替代与国家监测系统的对接传输**。E2B 传输回执在系统内留痕，实际传输
   通道由站点配置。
5. **不做法规符合性的最终判定**。就绪度评分与检查表是辅助排序工具，最终判定
   必须由具备资质的人员作出。
6. **不做电子签名的生物特征分量**。第二要素为 TOTP / 服务端挑战码。
7. **不做数据库文件级加密**，依赖操作系统文件权限与磁盘加密。
8. **不做多站点数据同步**。单实例本地部署，满足单部门级使用。
