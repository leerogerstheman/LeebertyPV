1. 如何开始
====================================================================
  双击 LeebertyPV.exe   （桌面启动器，独立窗口，托盘有 PV 图标）
  或 双击 start.bat     （带控制台窗口，可看日志；默认端口 8793）

  再次或换端口：  start.bat 9000        （或设 PV_PORT=9000）
  静默启动：       start-silent.bat     （日志在 logs\server.log）
  停止：           stop.bat
  手工生成演示数据：生成演示数据.bat（通常不需要，首次启动已自动完成）

  首次启动自动完成：建库 → 加载配置库（12 类 PV 流程）→ 创建演示账号 →
  无记录时生成演示数据 → 校验审计链 → 打开身份选择页。

3. 8 大领域 × 12 类流程
====================================================================
  领域                  流程（代码）
  ICSR 个例安全性报告   ICSR-EXP 快速报告（严重/非预期，15 日）
                        ICSR-REG 常规报告（非严重，30 日）
  SIGNAL 信号检测与评估 SIG-DET 信号检测；SIG-EVAL 信号评估
  PSUR 定期安全性报告   PSUR-COMP 定期报告编制（DLP + 60 日）
  RMP 风险管理          RMP-LIFE 风险管理计划全生命周期
  LIT 医学文献监测      LIT-MON 文献监测（检索→筛查→转交）
  AEFI 疫苗不良事件     AEFI-EXP 疑似 AEFI 快速处置（48h / 严重 2h）
  COMPLAINT 投诉与召回  COMP-HANDLE 投诉与召回联动
  GVP 药物警戒体系      PV-DEV 偏差；PV-CAPA 纠正与预防措施；
                        PV-CHANGE 变更控制

  时限要点：从 Day 0（首次获知且四要素齐备之日）起算——严重 15 日、
  非严重 30 日、死亡立即报告并 15 日内完成调查、境外严重 30 日、
  境外暂停/撤市 24 小时。随访不得延误首次报告。

4. 常用命令（项目根目录）
====================================================================
  node src\server.js                        启动服务（默认 127.0.0.1:8793）
  node src\daemon\monitor.js --once         手工跑一次后台扫描
  node scripts\seed-demo.js                 手工生成演示数据（--force 强制）
  node test\run-all.js                      跑全部 9 个测试套件
  node test\run-all.js e2e explorer         只跑指定套件
  node scripts\verify-audit.js              校验审计链完整性
  node scripts\verify-audit.js --seal "xxx" 生成完整性封印
  node scripts\verify-audit.js --record AES-2026-0001   单条记录历史
  node scripts\backup.js                    备份（VACUUM INTO + 密钥 + 配置）
  node scripts\backup.js --verify-only backups\<目录>\manifest.json  恢复演练
  node scripts\build-desktop.js             （重新）构建桌面启动器 exe
  node scripts\seed.js                      只加载配置库

5. 环境变量（PV_ 前缀）
====================================================================
  PV_BUILTIN_ACCOUNTS=1    启用 13 个演示身份 + 首次启动自动生成演示数据
                           （start.bat 默认开启；生产请显式置 0）
  PV_AUTO_SEED_DEMO=0      保留演示身份但保持空库
  PV_PORT=8793             端口（默认 8793）
  PV_HOST=0.0.0.0          局域网共享（务必前置 HTTPS，默认仅本机）
  PV_MONITOR=0             不启动后台工作流进程
  PV_SIG_2FA=0             关闭签名第二要素（不推荐，会不满足 §11.200）
  PV_FREEZE_ON_CHAIN_BREAK=0  审计链校验失败仍启动（仅调查用途）

  环境要求：Node.js 22.5+（内置 node:sqlite），零第三方依赖，断网可运行。
  窗口：LeebertyPV.exe 是原生 WinForms 应用窗口，不依赖 Edge / 任何浏览器。
